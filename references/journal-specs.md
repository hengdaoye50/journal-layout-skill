# 四刊版式参数（journal-specs）

本文件是 `journal-layout-skill` 的**版式参数真源**：四本刊（《政治学研究》《中国行政管理》
《公共管理学报》《管理世界》）的页面、边距、正文、标题层级、图表题注、页下注、参考文献、
页眉页脚的全部可复现参数。`scripts/journal_layout.py` 里的 `SPECS` 表以本文件为准
（该脚本 §41 行注释已声明这一点），本文件与脚本冲突时**先改脚本、不要改本表去迁就脚本**。

- 全部数值**pt**，`1 pt = 1/72 in = 0.352778 mm`，`1 cm = 28.3465 pt`。
- 每行字数、字步进、栏宽三者互相校验：改字号前先算"栏宽 ÷ 字步进"是否仍等于实测每行字数。

## 0 来源标注与判读约定

| 标记 | 含义 | 可信度 |
|---|---|---|
| 〔实测〕 | 本次用 PyMuPDF 直接测 `02_投稿指南与例文/` 下四篇例文 PDF 得到（2026-11-12 执行，方法见 §6） | 最高，是"真实印刷版式"的直接证据 |
| 〔须知〕 | 官方投稿须知 docx 原文措辞 | 高，但须知多数不讲字号、边距 |
| 〔脚本〕 | `06_处理脚本与临时数据/` 里真正落地过的排版脚本编码值 | 高（跑过、出过稿），但多为"近似取整" |
| 〔未确认〕 | 三方都没有可靠证据，或 PDF 中无法提取 | **不得凭印象填写** |

三条判读纪律：

1. **三方冲突时不取平均、不替作者拍板**：如实并列，并给一句"建议取哪个 + 为什么"。
2. 例文只有一篇，**不代表该刊全部文章**；凡"该刊一定如何"的结论都标〔未确认〕。
3. 《政治学研究》的须知只有"版权说明 + 引文注释规范"，**不含任何字号/边距/摘要要求**；
   《管理世界》的须知只有约 600 字投稿要求，**几乎不含版式细节**。这两刊的版式参数
   基本只能靠例文实测，须知一栏出现"未涉及"是正常的，不是漏查。

### 1.1 单栏 / 双栏（实测结论，四刊逐个明确）

判断方法：把正文文字块按奇偶页分别统计**左缘 x 的众数**。双栏会出现**两组**左缘
（两栏各一组）；单栏只有一组（缩进行会额外多一个 +2 字符的左缘，别误当成第二栏）。
同时用 mediabox 宽度减去左右极值墨迹得到版心宽，与"两组左缘差 − 栏宽 = 栏距"互校。

| 刊 | 实测结论 | 左缘（实测，pt） | 栏宽 / 栏距 | 通栏元素 |
|---|---|---|---|---|
| 政治学研究 | **单栏** | 仅 [78]（缩进行 102） | —（行宽 439.4） | —（本身单栏） |
| 中国行政管理 | **双栏** | 奇页 [51, 306]、偶页 [57, 312] | 232.5 / 22.7 pt | 题名区、摘要、关键词、中图分类号行、图 1 |
| 公共管理学报 | **双栏** | 奇页 [80, 323]、偶页 [51, 294] | 221.1 / 22.3 pt | 题名区、摘要区、表 1（通栏三线表） |
| 管理世界 | **单栏** | 仅 [71]（缩进行 90） | —（行宽 470.9） | —（本身单栏） |

> **"双栏/单栏"这件事上唯一有保留的是《管理世界》**：其例文 PDF 明确是单栏
> （9.51 pt 正文、47 字符/行、480.6 pt 行宽），但很多读者印象里纸刊是双栏。
> 本项目只有这一份 PDF 样本，**纸刊版式〔未确认〕**；若要求"像纸刊"，需另找纸刊样张核对。

### 6.1 页面尺寸与页边距（版心）

```python
import sys, os
sys.stdout.reconfigure(encoding='utf-8')
import fitz

PDF = r'D:\CODEX\担责换权\02_投稿指南与例文\《政治学研究》投稿指南及例文\“结对创变”：一种重塑中国区域协调发展的新机制_康红军.pdf'
doc = fitz.open(PDF)
pg0 = doc[0]
W, H = pg0.rect.width, pg0.rect.height
print('页面 %.3f x %.3f pt = %.2f x %.2f mm' % (W, H, W / 72 * 25.4, H / 72 * 25.4))

# 用"出现次数最多的正文字体+字号"筛出正文 span，避免页眉/脚注/题名干扰
from collections import Counter
cnt = Counter()
for i in range(1, min(doc.page_count, 10)):
    for b in doc[i].get_text('dict')['blocks']:
        if b['type'] != 0:
            continue
        for l in b['lines']:
            for s in l['spans']:
                if s['text'].strip():
                    cnt[(s['font'], round(s['size'], 2))] += len(s['text'])
body = cnt.most_common(1)[0][0]
print('正文字体 =', body)

for parity in (0, 1):                     # 0/1 = 奇偶页，用来发现镜像装订
    xs0, xs1 = [], []
    for i in range(1, min(doc.page_count, 10)):
        if i % 2 != parity:
            continue
        for b in doc[i].get_text('dict')['blocks']:
            if b['type'] != 0:
                continue
            for l in b['lines']:
                for s in l['spans']:
                    if (s['font'], round(s['size'], 2)) == body and s['text'].strip():
                        xs0.append(s['bbox'][0])
                        xs1.append(s['bbox'][2])
    if xs0:
        print('parity=%d  左边距 %.2f pt (%.2f cm)  右边距 %.2f pt (%.2f cm)  版心宽 %.2f pt'
              % (parity, min(xs0), min(xs0) / 28.3465, W - max(xs1), (W - max(xs1)) / 28.3465,
                 max(xs1) - min(xs0)))
doc.close()
```

要点：**必须按奇偶页分开统计**，否则《中国行政管理》《公共管理学报》的镜像边距会被
`min/max` 混成一个数。《政治学研究》《管理世界》两 parity 结果相同 = 不镜像。

### 6.2 字号（以及"字号到底真不真"）

```python
import sys
sys.stdout.reconfigure(encoding='utf-8')
import fitz
from collections import Counter
import re

PDF = r'...某例文.pdf'
doc = fitz.open(PDF)

# (a) 字号按字符数加权投票：只认占字符最多的 (font, size)
cnt = Counter()
for i in range(1, min(doc.page_count, 10)):
    for b in doc[i].get_text('dict')['blocks']:
        if b['type'] != 0:
            continue
        for l in b['lines']:
            for s in l['spans']:
                if s['text'].strip():
                    cnt[(s['font'], round(s['size'], 2))] += len(s['text'])
print(cnt.most_common(8))

# (b) 交叉校验：纯汉字行的"单字步进"必须 ≈ 字号；否则说明有字距或横向拉伸
body = cnt.most_common(1)[0][0]
PURE = re.compile(r'^[\u4e00-\u9fff]+$')
advs = []
for i in range(1, min(doc.page_count, 10)):
    for b in doc[i].get_text('rawdict')['blocks']:
        if b['type'] != 0:
            continue
        for l in b['lines']:
            for s in l['spans']:
                if s['font'] != body[0] or abs(round(s['size'], 2) - body[1]) > 0.05:
                    continue
                txt = ''.join(c['c'] for c in s['chars'])
                if len(txt) >= 8 and PURE.match(txt):          # 排除标点，标点宽度不固定
                    xs = [c['origin'][0] for c in s['chars']]
                    advs += [b2 - a2 for a2, b2 in zip(xs, xs[1:])]
                    break
advs = sorted(a for a in advs if a > 1)
med = advs[len(advs) // 2]
print('正文字号(span size) = %.2f pt   中位字步进 = %.2f pt   字距 ≈ %+.2f pt'
      % (body[1], med, med - body[1]))
doc.close()
```

判读：

- 步进 ≈ 字号 → 无字距（《中国行政管理》：字号 10.50、步进 10.56）。
- 步进 > 字号 → 有字距或横向拉伸：政治学研究 +0.78 pt、管理世界 +0.65 pt、
  公共管理学报 +1.12 pt（疑为 112% 横向拉伸）。**重现时按"每行字数"倒推最稳**：
  `每行字数 = 栏宽 ÷ 步进`，四刊分别是 **35 / 22 / 21 / 46 汉字**（文本层字符数会因半角
  数字与标点略多：37 / 22 / 22 / 47）。

### 6.3 行距（相邻基线差）

```python
import sys
sys.stdout.reconfigure(encoding='utf-8')
import fitz
from collections import Counter, defaultdict

PDF = r'...某例文.pdf'
doc = fitz.open(PDF)
cnt = Counter()
for i in range(1, min(doc.page_count, 10)):
    for b in doc[i].get_text('dict')['blocks']:
        if b['type'] != 0:
            continue
        for l in b['lines']:
            for s in l['spans']:
                if s['text'].strip():
                    cnt[(s['font'], round(s['size'], 2))] += len(s['text'])
body = cnt.most_common(1)[0][0]

deltas = Counter()
for i in range(1, min(doc.page_count, 10)):
    # 按"栏"分组：同一栏内基线才有意义（双栏刊尤其必须分组）
    cols = defaultdict(list)
    for b in doc[i].get_text('dict')['blocks']:
        if b['type'] != 0:
            continue
        for l in b['lines']:
            for s in l['spans']:
                if (s['font'], round(s['size'], 2)) == body and s['text'].strip():
                    cols[round(s['bbox'][0] / 30)].append(round(s['origin'][1], 1))
    for ys in cols.values():
        ys = sorted(set(ys))
        for a, b2 in zip(ys, ys[1:]):
            d = round(b2 - a, 1)
            if 5 < d < 60:                    # 滤掉段间距与跨栏跳跃
                deltas[d] += 1
print('行距候选（pt: 次数）=', deltas.most_common(6))
doc.close()
```

判读：取众数即可；正文 18.7/18.8 同时出现是取整噪声，取 18.8 或 18.75 都对。
**双栏刊必须按栏分组**，否则会把左右栏同高度的基线差算成 0。

### 6.4 分栏与栏宽

```python
import sys
sys.stdout.reconfigure(encoding='utf-8')
import fitz
from collections import Counter

PDF = r'...某例文.pdf'
doc = fitz.open(PDF)
for i in (1, 2):
    le = Counter()
    for b in doc[i].get_text('dict')['blocks']:
        if b['type'] != 0:
            continue
        for l in b['lines']:
            s = l['spans'][0]
            if s['text'].strip():
                le[round(s['bbox'][0])] += 1
    edges = sorted(k for k, v in le.items() if v >= 5)
    print('p%d 左缘候选 x =' % (i + 1), edges)   # 双栏会出现两组，如 [51, 306]
doc.close()
```

两组左缘即两栏；两栏左缘之差减去栏宽 = 栏距。中国行政管理实测
`[51, 306]` → 栏宽 232.5、栏距 22.7。**若同时出现 `[51, 306]` 与 `[57, 312]`，
是奇偶页镜像，不是三栏。**

### 6.5 页下注 / 页码 / 表格

- 页下注：取页面底部 150 pt 内、字号小于正文的 span，打印 `font/size/origin.y`，
  相邻 y 差即注文行距；`①-⑳`（U+2460–U+2473）出现的位置就是编号格式。
- 页码：在页面四边 80 pt 内的纯数字 span。
- 表格：`page.get_drawings()` 里 `width > 100 and height < 2` 的矩形即横线；
  横线间距 = 行高。**表题 y < 首条表线 y ⇒ 表题在上；反之在下。**
- 页眉线：`get_drawings()` 里横跨版心的细线。

**已知坑**：

1. `page.get_texttrace()` 对部分 Type0 字体（政治学研究、公共管理学报的 PDF）返回空，
   不要依赖它判字号，用 `rawdict` 的字符 origin 差。
2. 已转曲的页码（公共管理学报）只能拿到矢量矩形，`get_text()` 里是空的——
   遇到"应该有页码但搜不到"先怀疑转曲。
3. 中文 PDF 常见字体名是子集后缀（`FZSSK--GBK1-0`），不是"宋体"三个字；
   判断字体族看前缀：`FZSSK`＝方正书宋、`FZKTK`＝方正楷体、`FZHTK`＝方正黑体、
   `FZHei`/`SimHei`＝黑体、`FZKai`/`KaiTi`＝楷体、`FangSong`＝仿宋、`STXinwei`＝华文新魏。
